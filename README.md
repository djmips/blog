# blog

djmips's blog, served by GitHub Pages at https://djmips.github.io/blog/.

Plain Jekyll with no theme: write a page as Markdown with `layout: default` (and `title`,
`date`) in its front matter; `_layouts/default.html` and `assets/style.css` do the rest.
A post lives in its own folder, e.g. `spacewar/index.md` with its images beside it.
Drafts are kept elsewhere (private) until they are ready.
